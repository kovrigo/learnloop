# Odyssey: image manifest

Every image in this folder, one line each. Licence checked on 2026-10-08 in each museum's own data: The Met collection API (`isPublicDomain`), the Rijksmuseum linked-data record of the object's image (`id.rijksmuseum.nl`, VisualItem → `subject_to`), the Cleveland Museum of Art Open Access API (`share_license_status`), the Getty Museum linked-data record (`data.getty.edu`, rights on the image record: "Creative Commons Public Domain Dedication", clearance "download"). The Met API search endpoint is retired (2026-10-01): head candidates came from `v1.1/search` and the Met Open Access CSV (`Is Public Domain`), and every pick was checked again on `v1/objects/<id>` (`isPublicDomain: true`). Each file was opened and looked at: no nudity, no gore in what is shown.

Heads are artistic stand-ins, never portraits of the named people. One head plays one role in the whole video.

Heads cut out for the new roles: white paper border 21 px on a 428 px head (as the suitor PNGs). Museum objects cut out: border about 2% of the height (as the dinos). Not added: the Met 253627 Circe krater as a whole vessel (SC13): its upper register shows nude animal-headed men, so no clean whole-vessel picture exists (the booking-card crop stays).

Processing: downscaled to at most 2000 px on the long side, JPEG quality 85; PNG only where a shape is cut out (white paper border baked in). Crops are noted.
