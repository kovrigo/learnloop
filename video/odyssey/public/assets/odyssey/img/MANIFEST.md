Every image in this folder, one line each. Licence checked on 2026-10-08 in each museum's own data: The Met collection API (`isPublicDomain`), the Rijksmuseum linked-data record of the object's image (`id.rijksmuseum.nl`, VisualItem → `subject_to`), the Cleveland Museum of Art Open Access API (`share_license_status`).
